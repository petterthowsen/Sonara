## Midi

A selection of velocity points can be manipulated via 4 handles that show around the selection:
- top left handle tilts the beginning of the selection
- top right handle tilts the end of the selection
- bottom right handle scales (compresses or expand) the values

Note color can be changed to show velocity, note, or track color.

Sets of velocity and other lanes can be stored and recalled as presets. A Strings preset could show Velocity and MIDI cc1 for example. A Piano preset might have velocity and sustain CC.

We should also add features to show/hide stuff (tracks/channels/clips/notes) things based on the current playhead or region selection. Could be used in mixer, arranger and midi editor.

## Customizable view meters

You can switch meters to show a waveform - very cool.

## Direct Offline Processing / Bounce Processing Presets

We have planned a Bounce system similar to Bitwig. We can extend this to support bouncing with a specific preset with devices/effects, allowing you to for example bounce a piano midi part with lots of reverb, then reverse it and you have a reverse reverb effect before the piano part. Very handy!

## Efficient audio export batching

You can queue up several exports with various settings, which tracks to include, file formats etc.

You can also export with or without device inserts. This should probably mean, only the first device if it's a instrument device.

- useful for marking different things, for example hit points for film scoring.
